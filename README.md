# Personality — website

Brand site for the Personality app by dhurta.Inc, served at https://personality.dhurta.org.

Live face and body scanning run entirely in the visitor's browser; nothing is uploaded.

## Develop

```bash
npm install
npm run dev      # http://localhost:5320
npm run build    # type-check and build to dist/
```

Stack: React, Vite, TypeScript, Tailwind, Three.js, GSAP + Lenis, Lucide icons.
Content data (disciplines, meals) is exported from the app's own content files.
